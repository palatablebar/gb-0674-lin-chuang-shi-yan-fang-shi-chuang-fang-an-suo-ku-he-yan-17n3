# 访视与冻结定义

样例均为虚构编号，无身份信息。受试者入组日期由subjects表唯一确定，记录中的入组基准必须完全一致。采样日期和入组日期均转为Asia/Shanghai日历日期，差值为访视日；时刻先统一UTC。
方案选择按当前受试者assignment和该次发生时刻查半开生效窗，匹配必须唯一，不能使用全局最新方案。v1访视V1=[5,10)、V2=[12,17)；v2为[6,11)、[13,18)。受试者00001于10月10日转v2，其他受试者仍用v1。
PRIMARY计入访视完成，RETEST只替代该次测量值。首次记录必须唯一且在访视窗内。缺首次访视、重复首次和窗外访视均阻断，复检不能填补漏访或消除原偏离。
复检须引用同受试者同访视的PRIMARY，晚于原采样且不超过72小时，版本必须更高。同最高版本复检冲突时保留原结果并阻断。所有检验值以mg/dL输出，g/L乘100。
锁库须所有规定访视完成，无偏离、复检问题和隔离行。冻结包包含每条选定结果、原始行号、方案版本与访视窗。此工具只验证试验数据完整性，不做诊断判断或生产锁库。

## 迟到更正定义

更正动作三类：`ADD`（补录新记录，载荷须含除 id 外必填字段）、`UPDATE`（覆盖现有记录的业务字段，禁止改记录号）、`WITHDRAW`（从新批撤回记录，旧批保留）。更正状态四态：待处理（登记即此态，绝不参与计算）、已证实（证据闸门通过但批次尚未成功构建）、已生效（已产出衍生批次）、已拒绝（证据不足或人工驳回，终态）。

证据闸门三条件，全部显式可复核：证据文档号非空；`evidence_hash` 等于证据原文 SHA-256；证据原文包含目标记录号，且非撤回更正的原文中存在与更正后取值按 Decimal 零容差相等的数值（千分位与等价小数视为同值）。

每条更正持久化：更正号、血缘根批号、基础批号、动作、目标、载荷、更正前值、证据文档号/哈希/原文、状态、原因、尝试次数、最近失败原因、产出批号、登记与证实时刻、追加式事件日志。衍生批次 manifest 含 `lineage`：root_run_id、parent_run_id、correction_ids 与逐笔前后差异 diffs。活跃批次指针 `active_batches` 只在重建成功后移动；重建异常时旧批继续生效，纠正依据后可重试，同输入同规则批号不变。
